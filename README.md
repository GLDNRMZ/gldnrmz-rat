# gldnrmz-rat

Bug a stranger enough and he calls the cops on you.

Works on Qbox, QBCore and ESX with any target, inventory, notify and progress bar supported by [community_bridge](https://github.com/TheOrderFivem/community_bridge).

## Requirements

- community_bridge (with Qbox, QBCore or ESX)
- [bl_dialog](https://github.com/Byte-Labs-Studio/bl_dialog)

## Configuration

See `config.lua`. `Config.PoliceJobs` sets which jobs count as police for `Config.MinimumMethJobPolice`. Reward items must exist in your inventory (on ESX, use your money item instead of `cash`).
